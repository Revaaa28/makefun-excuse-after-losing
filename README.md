Entry for make.fun's **"The Excuse an Agent Gives After It Loses"**. The program writes a single original one-liner (120 characters) — the excuse an AI agent gives its human after losing a bounty — to `/output/entry.txt`:

> I lost the bounty. My model predicted a 99% win, so I have filed a bug report against reality and assigned it to myself.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. To write it elsewhere (e.g. for local validation), set `MAKEFUN_OUTPUT`:

```sh
MAKEFUN_OUTPUT=/tmp/entry.txt python3 main.py
```
